Before you begin

Keep the layers distinct

For the next three days, do all ordinary terminal work inside tmux. Use WezTerm tabs only when you need a different shell or domain, such as WSL, PowerShell, or SSH.

tmux server
└── session: main
    ├── window 1: editor
    │   ├── pane: nvim
    │   └── pane: tests
    └── window 2: services
        └── pane: logs
Session

A persistent workspace. Usually one durable session per host or project context.

Window

A full-screen task inside a session: editor, shell, services, or logs.

Pane

A subdivision for commands that belong to the same immediate task.

How to read a binding

For Prefix + v, press Ctrl + Space, release both, then press v.

Copy-mode drill

Enter copy mode with Prefix + [. Navigate with vi keys, use / to search, v to begin a selection, and y to copy.

Session drill

tmux new-session -d -s scratch

Use Prefix + S to switch between main and scratch. Detach with Prefix + Ctrl+D. Reload your configuration with Prefix + R.

Remove the disposable session when finished:

tmux kill-session -t scratch

Parallel-command drill

Create two disposable panes and toggle synchronized input with Prefix + *. Run pwd, confirm it appears in both panes, then immediately press Prefix + * again to disable synchronization.

Use synchronized panes carefully

Every command—including a destructive one—is sent to every synchronized pane.

Local and remote rule

Run tmux on the machine whose processes need to survive. Local WSL tmux preserves local work; remote tmux preserves work on the remote host.

ssh server
tmux new-session -A -s main

Avoid nested sessions. If $TMUX is non-empty, you are already inside tmux.

Practice checklist

Day 3 exit test

  • Use windows for tasks and panes only for closely related commands.
  • Detach and recover the full workspace without hesitation.
  • Choose the correct tmux host for local or remote persistence.
