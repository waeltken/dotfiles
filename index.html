Komorebi / Windows

Desktop windows, layouts, and monitor workspaces

Taskbar passthrough: Win+1..5 and Win+Shift+1..5 remain Windows pinned-app launch and new-instance shortcuts. Win+L remains Windows lock.

Main workspaces

Win+Alt+1..6

Focus main-monitor workspace 1 through 6.

Move to main workspace

Win+Alt+Shift+1..6

Move the current window to a main-monitor workspace.

Presentation workspaces

Win+Alt+Ctrl+1..3

Focus only presentation-monitor workspace 1 through 3.

Move to presentation workspace

Win+Alt+Ctrl+Shift+1..3

Move a window to a presentation-monitor workspace.

Focus direction

Win+Alt+HJKL

Focus left, down, up, or right.

Move direction

Win+Alt+Shift+HJKL

Move left, down, up, or right.

Cycle focus

Win+Alt+[]

Cycle focus to the previous or next window.

Promote

Win+Alt+Shift+Enter

Promote the focused window.

Stack

Win+Alt+←↓↑→

Stack left, down, up, or right.

Unstack / cycle stack

Win+Alt+; or Shift+[]

Unstack, or cycle the stack backward/forward.

Horizontal resize

Win+Alt++−

Increase or decrease horizontal size.

Vertical resize

Win+Alt+Shift++−

Increase or decrease vertical size.

Float / monocle

Win+Alt+T or F

Toggle floating or monocle mode.

Retile / pause

Win+Alt+Shift+R or P

Retile windows or toggle Komorebi pause.

Flip layout

Win+Alt+XY

Flip layout horizontally or vertically.

Window utilities

Win+Alt+QMS

Close, minimize, or toggle Komorebi lock.

Reload and control

Win+Alt+O or Shift+OI

Restart whkd, reload Komorebi, or toggle shortcuts.

WezTerm

Independent terminal contexts

Select tab 1–9

Ctrl+Shift+1..9

Select a WezTerm tab directly.

Previous tab

Ctrl+Shift+H

Select the previous WezTerm tab.

Next tab

Ctrl+Shift+L

Select the next WezTerm tab.

tmux / remote

Persistent sessions, windows, and panes

Prefix: Ctrl+Space. WezTerm tabs are outer contexts; tmux windows and panes are durable work inside them.

Select window 1–9

Prefix+1..9

Select a tmux window directly.

Previous / next window

Prefix+HL

Move between tmux windows.

Navigate panes

Prefix+HJKL

Select the pane left, down, up, or right.

Detach

Prefix+Ctrl+D

Detach while leaving the session running.

Choose session

Prefix+S

Open the session chooser.

Reload config

Prefix+R

Reload configuration and display confirmation.

Zoom pane

Prefix+Z

Toggle pane zoom.

Kill pane / new window

Prefix+C or Ctrl+C

Lowercase c kills a pane; Ctrl+C creates a window.

Right pane / sync

Prefix+L or *

Lowercase l selects the right pane; * toggles synchronization.

Local and remote workflow

tmux new-session -A -s main

Run after entering WSL or a remote host. Detach with Ctrl+Space, then Ctrl+D; rerun the command to reattach. Persistence and Continuum restoration apply on the host running tmux. No SSH ControlMaster or automatic remote wrapping is configured.

Shortcut strings mirror the maintained whkdrc, WezTerm, and tmux configuration.
